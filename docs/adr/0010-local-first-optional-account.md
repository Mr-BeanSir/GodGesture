# 本地优先、账户可选;自动同步不建长连接

GodGesture 离线完全可用:不登录不影响任何本地功能,云同步是增强项而非前提(拒绝"必须登录"的 SaaS 形态——工具类桌面软件强制登录劝退用户且断网即废)。

同步时机:本地改动防抖数秒后自动推送;启动时与定时(约 30 分钟)拉取;设置页常驻手动"立即同步"按钮兜底。不做 WebSocket/SSE 长连接实时推送——配置是低频小数据,跨设备秒级可见性收益不抵服务端连接状态维护与客户端重连逻辑的成本;代价(另一台在线设备最长一个轮询周期后才见到新配置)可接受。

设备撤销不依赖长连接下发:服务端在每个需要认证的请求验证访问令牌后,都会读取设备状态并核对其账户归属。已删除设备的后续请求立即失效;已通过认证的单个请求不与设备删除开启跨整个请求的事务,业务写入仍须正确处理其间的并发删除。

不参与同步的本机专属设置:开机自启、以管理员身份运行、托盘图标隐藏，以及 Node 插件源码、manifest、lockfile、依赖和在线来源。手势命令中的 `pluginId` 与其余用户配置(手势库、应用、触发角/摩擦边、偏好)随账户漫游。
