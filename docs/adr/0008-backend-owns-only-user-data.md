# 后端只承载用户数据;版本、模板与插件分发走 GitHub

"后端同步各种参数"的边界经澄清后确定:自建后端(NestJS + PG)只负责账户与**用户自己的配置数据**(手势库、应用、触发角、偏好设置,含用户已下载采纳的模板);不承担任何内容分发职责。

- 新版本信息与更新包:从 **GitHub Releases** 获取(Tauri updater 指向 GitHub 托管的更新清单)。
- 默认手势模板库:从**另一个专门的 GitHub 仓库**拉取;用户下载采纳后,模板内容并入其个人配置,随之云同步。
- 在线插件目录与插件源码:从公开 GitHub 仓库/Release 获取;用户确认后才下载和安装到本机插件
  工作区。源码、依赖和仓库来源不进入用户配置或云同步，配置只引用稳定 `pluginId`。
- 不做使用统计/遥测上报。

理由:分发内容是公开静态资源,GitHub 免费、免运维、带宽不占自有服务器;自有后端保持最小攻击面与最小存储职责。已知代价:大陆网络访问 GitHub 可能不稳,必要时未来可加镜像源,不改变此边界。
